# Smart Canteen 🍽️

เว็บแอปต้นแบบสำหรับสั่งอาหารในมหาวิทยาลัย สลับภาษาไทย–อังกฤษได้ รองรับมือถือและคอมพิวเตอร์

## สิ่งที่ทดลองได้

- เลือกร้าน ค้นหาอาหาร และกรองเมนูยอดนิยมหรือมังสวิรัติ
- ปรับความเผ็ด เพิ่มไข่ดาว และจัดการจำนวนในตะกร้า
- เลือกรอบรับอาหาร โดยรอบเต็มไม่สามารถเลือกได้
- ชำระเงินจำลอง พร้อมรหัสรับอาหาร
- ติดตามสถานะ รับออร์เดอร์ → กำลังทำ → พร้อมรับ → รับแล้ว
- ยกเลิกก่อนอาหารพร้อม พร้อมสถานะคืนเงินจำลอง
- สลับภาษาไทย–อังกฤษ โดยไม่ล้างตะกร้า

## ขอบเขตของต้นแบบ

ร้าน ราคา คะแนน เวลารอ และรอบรับอาหารเป็นข้อมูลตัวอย่าง ไม่มีการสั่งอาหารจริง ไม่มีการชำระเงินจริง และ QR ไม่สามารถใช้ชำระเงินได้

เวลารอยังไม่เชื่อมต่อ AI หรือครัวจริง เป็นตัวอย่างสำหรับนำเสนอแนวคิด ออร์เดอร์เปลี่ยนสถานะทุก 25 วินาทีเพื่อสาธิต และมีปุ่มทดลองขั้นตอนถัดไป

ตะกร้าและออร์เดอร์เก็บในหน่วยความจำของแท็บเท่านั้น รีเฟรชแล้วจะเริ่มใหม่ ส่วนภาษาที่เลือกจะจำไว้ในเบราว์เซอร์ ไม่มีฐานข้อมูลหรือการเข้าสู่ระบบ

## อัปโหลดขึ้น GitHub

1. แตกไฟล์ ZIP นี้
2. สร้าง repository ใหม่ใน GitHub
3. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมด **ภายใน** โฟลเดอร์ที่แตกไฟล์ ให้ `index.html` อยู่ระดับแรกของ repository
4. บันทึกการเปลี่ยนแปลงด้วย Commit changes
5. เปิด Settings → Pages แล้วเลือก Deploy from a branch
6. เลือก branch `main` และโฟลเดอร์ `/ (root)` จากนั้น Save
7. เมื่อ GitHub Pages สร้างเว็บไซต์เสร็จ จะมีลิงก์เว็บแสดงในหน้านั้น

เอกสารทางการ: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

การเปิด repository เป็น Public จะทำให้ผู้อื่นเห็นโค้ดและภาพใน repository ได้ ใช้เฉพาะไฟล์โครงการในชุดนี้ ไม่ต้องอัปโหลดไฟล์ส่วนตัวหรือข้อมูลลับ

## เปิดในเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ได้โดยตรง หรือเปิดผ่าน Live Server ใน VS Code

หากมี Python:

```sh
python3 -m http.server 8000
```

จากนั้นเปิด http://localhost:8000

ไม่มีขั้นตอนติดตั้งแพ็กเกจหรือ build

## โครงสร้างไฟล์

- `index.html` — หน้าแอป
- `style.css` — สี เลย์เอาต์ และการแสดงผลบนมือถือ
- `app.js` — ข้อมูลตัวอย่าง ภาษา และขั้นตอนสั่งอาหาร
- `assets/hero.png` — ภาพประกอบหน้าหลัก
- `assets/menu.png` — ภาพเมนูอาหาร
- `.nojekyll` — ให้ GitHub Pages เสิร์ฟไฟล์โดยตรง

## ปรับแก้

- เปลี่ยนคำแปลที่ตัวแปร `d` ใน `app.js`
- เปลี่ยนร้านที่ `stores` และเมนู/ราคาที่ `meals`
- เปลี่ยนโทนสีที่ `:root` ใน `style.css`

ภาพอาหารสร้างขึ้นเพื่อประกอบต้นแบบ ไม่ใช่ภาพของร้านจริง ฟอนต์โหลดจาก Google Fonts หากไม่มีอินเทอร์เน็ต แอปจะใช้ฟอนต์สำรองในเครื่อง

## ก่อนนำไปใช้รับออร์เดอร์จริง

ต้องเพิ่มระบบร้านค้า ฐานข้อมูล การจัดการจำนวนรอบแบบส่วนกลาง และระบบชำระเงินที่ยืนยันรายการฝั่งเซิร์ฟเวอร์ ต้นแบบนี้ยังไม่มีส่วนเหล่านั้น
